# Benchmark Results

This directory stores generated benchmark outputs.

## Structure

- `tables/` contains machine-readable result tables.
- `figures/` contains figures generated from benchmark outputs.

Results are generated from the public C-MAPSS FD001 dataset and are not committed until the corresponding experiment has been executed and checked.

The scripts that generate each result should record the dataset partition, temporal window, model configuration, random seed, and evaluation metrics needed to reproduce the output.
